# Career Journey

I view software engineering as a craft of continuous growth. From my first lines of production code as an intern to architecting enterprise systems today, my journey has been defined by a commitment to quality, accessibility, and clean architecture.

### Therap (BD) Ltd.

**The Enterprise Era** _July 2024 — Present_

At Therap, my focus shifted to high-stakes, US-market healthcare software where security and inclusivity are paramount. I progressed from an Associate to a Software Engineer, taking on greater ownership of technical standards.

- **Software Engineer** (_July 2025 — Present_)
- **Associate Software Engineer** (_July 2024 — June 2025_)

During this time, I:

- Architected modular, type-safe UI components using **React** and **TypeScript**, ensuring 99% type coverage.
- Led accessibility (A11y) initiatives, implementing **WCAG 2.1** standards and conducting manual audits with **NVDA** and **JAWS**.
- Scaled complex state management using **Redux Toolkit** to handle massive enterprise data flows.
- Refined internal design systems to maintain UI consistency across global modules.

My time at Bizzntek was a period of rapid evolution, moving through three distinct roles in two years. This is where I transitioned from a student at the University of Rajshahi to a professional engineer.

- **Associate Software Engineer** (_April 2023 — June 2024_)
- **Trainee Software Engineer** (_October 2022 — March 2023_)
- **Software Engineer Intern** (_July 2022 — September 2022_)

Key contributions included:

- Contributing to full-stack project deliveries, ensuring a seamless connection between frontend UI and backend logic.
