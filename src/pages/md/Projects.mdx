### 01. TrainMate (Flagship Project)

** Train & Metro Information Platform**

TrainMate is an end-to-end solution designed to simplify urban commuting. It provides commuters with required information, route planning, and schedule management for train and metro systems.

- **Role:** Lead Developer (End-to-End)
- **Status:** Published & Live
- **Links:** [Web App](https://trainmate.rastercell.com/) | [Play Store](https://play.google.com/store/apps/details?id=com.rastercell.trainmate) | [Source Code](https://github.com/rahathossenmanik/trainmate)

#### The Tech Stack

- **Frontend:** React, TypeScript, Redux Toolkit, Tailwind CSS.
- **Backend:** Node.js, Express, PostgreSQL.
- **Infrastructure:** AWS (Hosting), RESTful APIs for real-time transit data.

#### Key Engineering Challenges

- **Real-time Data Sync:** Implemented efficient polling and data-fetching logic to ensure commuters receive live updates on train locations and delays.
- **Complex Routing Logic:** Developed algorithms to calculate the most efficient metro routes, including transfers and estimated time of arrival (ETA).
- **High Availability:** Optimized the backend to handle high traffic loads during peak commuting hours, ensuring the app remains responsive when users need it most.

### 🛠️ My "Definition of Done" for Projects

Every project I ship—whether public or private—must meet my internal engineering standards:

1.  **Accessible:** Semantic HTML and ARIA patterns as a requirement.
2.  **Type-Safe:** Leveraging TypeScript to catch errors at compile-time.
3.  **Documented:** Clean code is good, but a well-written README is better.
4.  **Performant:** Optimized for low latency and fast "First Contentful Paint."
